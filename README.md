# 🍥 SHINOBI — O RPG de Ninjas

Um RPG de mesa de **Naruto** baseado no sistema **Storyteller / Storytelling** da White Wolf (como *Vampiro: A Máscara* e *Exalted*).

👉 **Leia o manual em: [https://marcellogalhardo.dev/naruto-rpg/](https://marcellogalhardo.dev/naruto-rpg/)** (ou direto no arquivo [`index.md`](./index.md))

---

## Filosofia do Projeto

Este projeto adapta o universo de Naruto para um jogo de mesa tático, narrativo e equilibrado. Nossos princípios são:

- **Fiel ao Mangá Original:** O livro usa apenas o mangá original de Naruto como base. Elementos exclusivos do anime (fillers e filmes) ficam de fora.
- **Equilíbrio Acima de Tudo:** Todo personagem deve ser útil e divertido na mesa. O sistema evita mecânicas quebradas — nenhum clã é melhor que todos os outros, e evitamos a escalada de poder exagerada do final do *Shippūden*. Ser fiel à obra não pode destruir a graça do jogo.
- **Auto-suficiente (*Self-sufficient*):** Você não precisa de outros livros da White Wolf para jogar. Este manual traz todas as regras, atributos, habilidades, clãs, disciplinas, técnicas e guia do narrador.
- **Linguagem Simples e Direta:** Escrito em **Português do Brasil**, seguindo os princípios do *Simplified Technical English* (STE). Usamos frases curtas, palavras diretas e regras fáceis de consultar durante a sessão.
- **Markdown para Web e PDF:** O livro é mantido em Markdown no arquivo [`index.md`](./index.md) para publicação direta no GitHub Pages e fácil conversão para PDF.

## Como Contribuir

Quer ajudar a melhorar o sistema, corrigir um texto ou sugerir ajustes de balanceamento? Siga este fluxo:

1. **Abra uma Issue primeiro:** Não envie mudanças de regras sem conversa prévia. Abra uma *Issue* descrevendo o problema, a sugestão de balanceamento ou a modernização de regra que você quer propor.
2. **Discuta e aguarde aprovação:** Modernizações no sistema e ajustes de poder são bem-vindos, mas **precisam de aprovação** antes de entrar no manual.
3. **Envie um Pull Request:** Após a ideia ser aprovada na *Issue*, faça um *Pull Request* alterando o [`index.md`](./index.md).
   - Mantenha o texto curto, claro e direto (estilo *Simplified Technical English* em português).
   - Respeite os limites de poder e custo de Chakra/PE definidos no manual.
